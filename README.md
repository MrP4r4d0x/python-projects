# 🚀 **Проекты**

## [🔮 Magic 8-Ball](/magic-8-ball)
Консольная программа, имитирующая шар предсказаний. Задавайте вопросы и получайте случайные ответы из 20 вариантов.
**Технологии:** Python, модуль random, консольный ввод/вывод
**Концепции:** функции, циклы, обработка пользовательского ввода, модульная архитектура

## [📊 Log Analyzer CLI](/log-analyzer-cli)
Консольная утилита для анализа HTTP-логов. Выводит топ IP-адресов, URL и кодов ответа сервера.
**Технологии:** Python, argparse, collections.Counter, pathlib
**Концепции:** работа с файлами, парсинг строк, командная строка, статистический анализ

# 🛠  **Как использовать этот репозиторий**

Каждый проект находится в отдельной папке. Для запуска перейдите в папку проекта и выполните:
```bash
# Magic 8-Ball
cd magic-8-ball
python3 main.py

# Log Analyzer CLI
cd log-analyzer-cli
python3 log_analyzer.py -f logs
```
