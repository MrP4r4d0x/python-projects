# 🚀 **Проекты**

## [🔮 Magic 8-Ball](/magic-8-ball)
Консольная программа, имитирующая шар предсказаний. Задавайте вопросы и получайте случайные ответы из 20 вариантов.
**Технологии:** Python, модуль random, консольный ввод/вывод
**Концепции:** функции, циклы, обработка пользовательского ввода, модульная архитектура

## [📊 Log Analyzer CLI](/log-analyzer-cli)
Консольный анализатор серверных логов с детализацией по IP-адресам.  
Поддерживает форматы **Nginx (access.log)** и **Syslog (sshd)**.  
Для каждого источника показывает распределение запросов, ошибок, URL, методов и временных меток.  
**Технологии:** Python, argparse, re, collections (Counter, defaultdict), pathlib  
**Концепции:** ООП, парсинг регулярными выражениями, агрегация данных, работа с файлами, командная строка  
**Особенности:** модульная архитектура парсеров, подготовлены 70+ автотестов, задел под новые форматы (JSON-логи, медленные запросы БД).

# 🛠  **Как использовать этот репозиторий**

Каждый проект находится в отдельной папке. Для запуска перейдите в папку проекта и выполните:
```bash
# Magic 8-Ball
cd magic-8-ball
python3 main.py

# Log Analyzer CLI
cd log-analyzer-cli
python3 log_analyzer.py -f nginx_sample.log -t nginx --top 5
```
