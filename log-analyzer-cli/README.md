# 📊 Log Analyzer CLI

Консольная утилита на Python для быстрого анализа HTTP-логов. Извлекает и выводит топ IP-адресов, URL и кодов ответа, помогая находить самых активных клиентов, популярные страницы и ошибки сервера.

## 📋 О проекте

Инструмент создан для упрощения рутинной проверки логов веб-сервера (Nginx, Apache). Вместо ручного разбора многомегабайтных файлов можно за секунду получить сводку самых частых записей.  
Проект выполнен в ходе самостоятельной практики по работе с файлами, строками и модулем `argparse`.

## ⚙️ Особенности реализации

*   Чтение логов построчно без загрузки всего файла в память.
*   Подсчёт статистики с помощью `collections.Counter`.
*   Гибкая настройка количества отображаемых позиций (`--top`).
*   Проверка существования файла перед анализом.
*   Минимальные зависимости — только стандартная библиотека Python.

## 📌 Используемые технологии и концепции

*   **Типы данных:** строки (`str`), кортежи (`tuple`), счётчики (`Counter`).
*   **Основные конструкции:** переменные, функции, условный оператор.
*   **Циклы:** `for` для обхода строк файла.
*   **Модули:**
    *   `argparse` — обработка аргументов командной строки.
    *   `pathlib.Path` — проверка существования файла.
    *   `collections.Counter` — удобный подсчёт частот.
*   **Работа с файлами:** контекстный менеджер `with open(...)`.
*   **Структура кода:** функция `main()` и точка входа `if __name__ == "__main__"`.

## 🚀 Как запустить

### Требования
*   Python 3.6 или выше.

### Запуск программы
1.  Скачайте файл `log_analyzer.py`.
2.  Откройте терминал в папке с файлом.
3.  Выполните команду, указав путь к лог-файлу:
    ```bash
    python3 log_analyzer.py -f sample.log
    ```
### Параметры
*   -f, --file — обязательный, путь к файлу логов.
*   --top — число строк в каждом топе (по умолчанию 10).

## 📄 Формат логов
Программа ожидает строки, в которых как минимум 9 полей, разделённых пробелами. Анализируются:

*   Поле 0 — IP-адрес (например 192.168.1.45)

*   Поле 6 — URL (/about, /images/logo.png)

*   Поле 8 — HTTP-код ответа (200, 404)

Строки короче 9 полей игнорируются.

## 📄 Структура кода
*   **Функции:**
    *   `read_file()` — чтение лога и подсчёт статистики.
    *   `display_info()` — форматированный вывод топа.
    *   `main()` — точка входа, настройка argparse и запуск.
*   **Объекты:**
    *   `ip_arr`, `code_arr`, `url_arr` — счётчики `Counter` из модуля `collections`.
